HEXADENCE PLAYER GUIDE

Current version: 0.3.2

WHAT YOU NEED

- A 64-bit installation of Java 21 or newer.
- An internet connection if you want to use online multiplayer.

No additional installation is required. Download the supplied .jar file from
the shared Google Drive link and save it anywhere on your computer. Open the
file to start the game.

If double-clicking it does not work, open a terminal in the folder containing
the downloaded file and run:

    java -jar "Hexadence-0.3.2.jar"


VERSION COMPATIBILITY

Version 0.3.2 is the currently supported release. Earlier versions may be
missing features and are not guaranteed to connect to the online multiplayer
server. For the best experience, all players should use the current version.
